# Créditos de la página de inicio

## Diseño

La estructura de la página de inicio se basa en la plantilla **Landing Page** de Start Bootstrap: portada con fotografía, franja de perfiles, bloques alternados de imagen y texto, y llamada a la acción.

- Fuente: https://github.com/StartBootstrap/startbootstrap-landing-page
- Licencia: MIT. Copyright (c) 2013-2023 Start Bootstrap LLC.

Los estilos se reescribieron para SysFood en `static/css/sysfood.css`, en la sección «Portada».
